# 추가 동사 후보 조사: 모션 디자이너 관점

- 기준 캐릭터: `male_01`
- 기준 장면: 어린이 동화의 숲길, 성, 바위, 마법 공간처럼 한 인물이 화면에 보이는 장면
- 판정 기준: 다른 인물 없이 수행 가능할 것, 한 장면/짧은 클립에서 동작 의미가 읽힐 것, 현재 캐릭터의 모험가 스타일과 어울릴 것
- 현재 승인 목록: `걷다/달리다`, `뛰어오르다`, `둘러보다`, `마법을 쓰다`, `앉다`, `일어서다`, `손 흔들다`, `멈추다`
- 제외 전제: `turn`은 전용 회전 에셋 부족으로 거절된 상태이며 이번 후보에 다시 넣지 않는다.

## 조사 근거

1. `tools/next_actions/red_team_review.md`에서 현재 승인 목록을 확인했다. `sit`과 `stand`은 완성 판정이고, `wave`와 `stop`은 프로토타입 판정이므로 같은 동작의 변형을 새 후보로 세지 않았다.
2. `assets/characters/motion_sheets/male_01_crawl_cycle_v1.png`는 낮은 자세에서 손·발을 교차해 전진하는 4x2 포즈 시트다. `output/video_previews/male_01_crawl_v1_contact.png`에서도 한 인물의 기어가는 실루엣이 한눈에 읽힌다.
3. `assets/characters/motion_sheets/male_01_climb_cycle_v1.png`는 웅크림, 손 뻗기, 발 올리기, 상체 상승 포즈를 갖지만 벽 자체는 에셋에 없다. 별도 프리뷰가 돌벽을 추가한 이유도 행동의 기준물을 만들기 위해서다.
4. `assets/characters/motion_sheets/male_01_action_sheet_v21.png`에는 손 들기, 이마에 손 대기, 양손 모으기, 손 내밀기, 검을 든 자세가 있다. 단일 키포즈는 보조 자료로는 쓸 수 있지만, 박수·끄덕임·가리키기처럼 반복 또는 정확한 손 모양이 필요한 동작의 완성 시트는 아니다.
5. `assets/characters/motion_sheets/male_01_interaction_cycle_v22.png`는 열린 손과 내미는 손이 중심이다. 상대나 물건 없이 사용하면 `건네다`, `받다`, `대화하다`로 의미가 고정되지 않으므로 solo 후보와 분리한다.
6. `assets/characters/motion_sheets/male_01_battle_cycle_v22.png`는 검을 들고 휘두르는 포즈가 중심이다. 현재 남자아이 모험가 스타일에는 맞지만, 전투는 위협·상대·대상이 있어야 의미가 완성되므로 별도 의존군으로 둔다.

### 1. 기어가다

- 읽히는 핵심: 상체가 지면 가까이 있고, 손과 무릎이 반대쪽으로 교차하며 이동한다. 서기·걷기·점프와 실루엣이 확실히 다르다.
- 현재 가능성: 높음. 이미 8포즈 `crawl_cycle`과 `male_01_crawl_v1` 프리뷰가 있다. 다만 프리뷰는 `journey` 경로에 얹혀 있으므로, 단독 동사로 등록할 때는 수평 이동과 낮은 접지를 우선해야 한다.
- 프레임 순서: `서기/대기` -> `몸 낮추기` -> `오른손+왼무릎 전진` -> `왼손+오른무릎 전진` -> `반대 교차` -> `1~2회 반복` -> `속도 줄이기` -> `낮은 자세 hold`.
- 장면 계약: 낮은 덤불, 문틈, 동굴처럼 낮은 통로가 있으면 의미가 더 빨리 읽힌다. 장애물이 없어도 구현은 가능하지만, `기어오르다`와 혼동되지 않도록 수직 상승을 금지한다.

### 2. 기어오르다

- 읽히는 핵심: 손이 위쪽을 잡고, 한 발을 올린 뒤 골반과 몸통이 실제로 상승한다. 평지에서 네 발로 움직이는 장면과 반드시 분리한다.
- 현재 가능성: 중간. `climb_cycle`은 상승 포즈를 제공하지만, 시트만 놓고는 벽을 오르는지 점프하는지 애매하다. 프리뷰처럼 화면 한쪽에 안정된 돌벽을 놓고 손·발 접점을 맞춰야 한다.
- 프레임 순서: `벽 앞 접근` -> `손을 위쪽 홈에 뻗기` -> `한 발 디디기` -> `팔로 당기며 몸통 상승` -> `다른 손·발 교대` -> `높이 변화` -> `턱 위로 올라서기` -> `상단 균형 hold`.
- 의존성: 다른 인물은 필요 없지만 환경 기준물은 필수다. 보고서의 solo는 “파트너 없이 혼자”라는 뜻이며, `벽/바위/사다리` 의존성을 숨기지 않는다.

### 3. 박수치다

- 읽히는 핵심: 양손이 좌우로 벌어졌다가 가슴 앞에서 정확히 만나고 다시 벌어진다. 손 접촉 순간을 짧게 hold하면 작은 화면에서도 동작이 읽힌다.
- 현재 가능성: 부분 가능. `action_sheet`의 양손 모음 포즈는 접촉 키로 쓸 수 있으나, 한 장뿐이면 손을 모으는 제스처나 마법 준비로 오인될 수 있다.
- 프레임 순서: `팔을 편 중립` -> `양팔을 가슴 앞쪽으로 모으기` -> `손바닥 접촉 hold` -> `손을 반 박자 튕겨 벌리기` -> `두 번째 접촉` -> `웃는 표정의 박수 hold`.
- 에셋 요구: 손바닥의 앞면이 보이는 접촉 포즈와 팔꿈치가 벌어진 반동 포즈를 추가한다. 검이나 마법 효과는 넣지 않는다.

### 4. 기지개를 켜다

- 읽히는 핵심: 양팔을 머리 위로 길게 뻗고, 가슴과 허리가 펴지며, 발은 바닥에 남는다. 점프와 구별하려면 공중 부양이나 두 발 이탈을 금지한다.
- 현재 가능성: 낮음~중간. 직접 재사용할 포즈는 없지만 male_01의 망토와 전신 비율에는 자연스럽다. 아침 숲길, 성문 앞 휴식, 잠에서 깬 장면에 잘 맞는다.
- 프레임 순서: `어깨가 처진 중립` -> `팔꿈치 굽혀 양손 상승` -> `팔을 머리 위로 완전히 뻗기` -> `가슴·등 신전 hold` -> `숨 내쉬며 팔 내리기` -> `편안한 stand hold`.
- 에셋 요구: 양팔이 망토와 겹치지 않는 정면/3⁄4 포즈, 발을 고정한 두 발 접지, 얼굴이 가려지지 않는 손 위치가 필요하다.

### 5. 가리키다

- 읽히는 핵심: 시선이 먼저 이동하고, 팔이 한 방향으로 뻗은 뒤 검지가 한 지점을 고정한다. 양손을 펼친 `건네기`와 달리 손가락 하나의 방향성이 있어야 한다.
- 현재 가능성: 중간. `action_sheet`와 `interaction_cycle`의 열린 손은 팔 경로 참고용으로만 쓰고, 실제 검지 포즈는 새로 만든다.
- 프레임 순서: `중립` -> `대상을 바라보기` -> `팔꿈치 들어 올리기` -> `팔과 검지 완전 신전` -> `지시 방향 hold` -> `팔 회수`.
- 의존성: 파트너는 필요 없다. 단, 화면 안에 성문·빛·바위 같은 정적 목표를 두어야 “가리키다”가 “손 내밀다”보다 빨리 읽힌다.

### 6. 고개를 끄덕이다

- 읽히는 핵심: 눈과 얼굴이 유지된 상태에서 턱과 상체가 짧게 아래로 내려갔다가 돌아온다. 팔이나 소품을 움직이지 않아야 한다.
- 현재 가능성: 낮음. 현재 전신 시트는 얼굴 표정은 유지하지만 고개 각도의 연속 키가 없다. 기존 `investigate`와 겹치지 않도록 좌우 탐색이 아니라 위아래 동작으로 설계한다.
- 프레임 순서: `정면 중립` -> `턱 10~15도 하강` -> `가장 낮은 지점 hold` -> `중립 복귀` -> `짧은 두 번째 끄덕임` -> `시선 고정`.
- 에셋 요구: 얼굴 해상도가 충분한 중경 또는 상반신 컷, 목·어깨가 자연스럽게 연결된 4~6포즈가 필요하다. 전신 원경용 기본 동사로는 우선순위를 낮춘다.

### 7. 무릎 꿇다

- 읽히는 핵심: 몸이 무너지지 않고 한쪽 또는 양쪽 무릎을 의도적으로 바닥에 댄 뒤, 상체가 세워진 상태로 멈춘다.
- 현재 가능성: 중간. `climb_cycle`에 한쪽 무릎을 낮춘 포즈가 있지만, 그 포즈만 반복하면 착지나 돌진 준비로 보인다. `sit_cycle`과도 혼동될 수 있다.
- 프레임 순서: `두 발 stand` -> `무릎 굽힘` -> `한쪽 무릎 접촉` -> `양 무릎 접촉` -> `상체를 세운 kneel hold` -> `고개를 들고 주변 확인` -> `stand로 회복`.
- 에셋 요구: 양 무릎이 보이는 정면/3⁄4 포즈, 바닥 접촉 그림자, 앉기와 다른 엉덩이 높이가 필요하다.

## 제작 순서 제안

1. **기어가다**: 현재 8포즈 시트와 프리뷰를 기반으로 단독 동사 후보를 먼저 확정한다. 낮은 통로 장면을 함께 고정하면 판독성이 가장 안정적이다.
2. **기어오르다**: `climb_cycle`을 유지하되, 돌벽 또는 사다리의 손·발 접점과 상승 경로를 먼저 맞춘다. 기준물 없이 평지에서 테스트하지 않는다.
3. **박수치다 / 기지개를 켜다**: 소품 없이도 읽히는 전신 stationary 동작으로 묶어 새 4~6포즈 시트를 만든다.
4. **가리키다**: 정적 목표가 있는 동화 장면을 정하고, 검지 방향이 보이는 중경 키포즈를 만든다.
5. **고개를 끄덕이다 / 무릎 꿇다**: 화면 구도와 접지 품질을 함께 검증한 뒤 추가한다. 전자는 중경, 후자는 전신이 필수다.

### 구현 전 체크리스트

- 매 후보는 `male_01`의 파란 튜닉, 붉은 망토, 부츠, 얼굴 비율을 유지한다.
- 각 클립은 `prepare -> act -> recover`의 세 구간을 갖고, 의미가 결정되는 자세를 최소 2~4프레임 hold한다.
- 배경 이동만으로 행동을 만들지 말고, 손·머리·몸통·발 중 최소 두 부위의 변화를 확인한다.
- 파트너나 물체가 필요하다고 판정한 후보는 solo 동작 목록에 섞지 않고 별도 상호작용/환경 트랙으로 보낸다.
- 이번 보고서 작성에서는 공용 provider, 기존 에셋, 기존 구현 파일을 수정하지 않았다.
